# 📊 HR Data Analytics Dashboard

An interactive HR Data Analytics Dashboard built using **Python, Streamlit, Pandas, NumPy, Matplotlib, and Machine Learning**. The project analyzes employee data to provide actionable insights on workforce trends, employee performance, attrition, recruitment, and overall HR metrics.

---

## 🚀 Features

- 📈 Interactive HR Dashboard
- 👨‍💼 Employee Data Analysis
- 📊 Attrition Analysis
- 📉 Department-wise Performance Insights
- 🎯 Recruitment & Hiring Analytics
- 📌 Employee Demographics Visualization
- 🔍 Search & Filter Functionality
- 📄 CSV Data Upload
- 🤖 Machine Learning-based Predictions
- 📱 Responsive Streamlit Interface

## 📥 Installation

Clone the repository

```bash
git clone https://github.com/jayjeswani1234/HR-Data-Analytics.git
```

Navigate to the project directory

```bash
cd HR-Data-Analytics
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will be available at:

```
http://localhost:8501
```
